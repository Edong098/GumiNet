# Catatan historis pengguna

Semua angka dalam JSON/CSV di folder ini berasal dari prompt pengguna dengan
`source: user_reported_google_colab`; **bukan reproduksi oleh Codex**. Persen disimpan
sebagai persen (90.5 berarti 90,5%), standar deviasi sebagai percentage points dan
menggunakan sample std ddof=1 saat dihitung ulang. Nilai kosong/null berarti tidak tersedia.
Summary yang dilaporkan dipertahankan terpisah dari hitungan ulang dan delta pembulatannya.
Eksperimen D1 W075 seed42 pada tabel refinement merupakan run yang sama dengan
multi-seed refined (presisi berbeda), bukan observasi independen tambahan.

Tidak tersedia log asli, checkpoint, gambar kesalahan, versi library, hash split atau
notebook Intel di repositori awal. Confusion matrix hanya angka yang dilaporkan;
tidak dibuat gambar/log/checkpoint historis baru. Seed dan identitas checkpoint test
Nano/Tiny belum diketahui. Tabel lengkap tujuh model awal tidak disediakan.
